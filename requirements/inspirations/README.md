# inspirations

Références apportées par le client : sites qu'il aime, captures, moodboards, produits cités en
exemple.

Vide pour l'instant — ce README tient le dossier, que Git ne conserverait pas autrement.

**Ce ne sont pas des maquettes.** Une inspiration vient de l'extérieur et ne s'édite pas ; une
maquette est produite par le projet et vit dans [`ui-ux-design/`](../../ui-ux-design/). Confondre les
deux ferait entrer dans l'atelier des fichiers que personne n'a le droit de modifier.

Nommer d'après la source, pas d'après l'impression qu'elle donne : `linkedin-recruiter-recherche.png`
se retrouve dans six mois, `inspiration-3.png` non.
