# Design

Identité visuelle de Shortlist et son implémentation dans `webapp/` : logo, couleurs, typographie,
espacement, formes, mouvement, et le kit de composants qui les porte.

- Related : [../index.md](../index.md)

## Contenu de la section

| Document                                     | Rôle                                                                                                                                    |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| [brand-guidelines.md](./brand-guidelines.md) | Charte de marque : logo, nuancier, tokens sémantiques, typographie, espacement et gabarits, formes, mouvement, accessibilité, principes |
| [design-system.md](./design-system.md)       | Implémentation : cascade à trois étages, fichiers propriétaires, utilitaires à employer, interdits, galerie UX Kit                      |

## Par où commencer

- **Dessiner un écran** — ouvrir la galerie `/artefacts/ux-kit` sur l'espace public, puis
  [design-system.md](./design-system.md) pour les utilitaires et les interdits.
- **Trancher une valeur** (une teinte, une taille, un rayon) —
  [brand-guidelines.md](./brand-guidelines.md).
- **Ajouter un token** — la procédure est en fin de
  [design-system.md](./design-system.md).
